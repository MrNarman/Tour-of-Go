# Tour of Go

A collection of Go programming exercises and practice projects as I learn the language and strengthen my software development fundamentals.

## About

This repository contains my solutions to exercises from [A Tour of Go](https://go.dev/tour/), along with additional practice as I explore Go's syntax, core concepts, and programming patterns.

The goal is to build a strong foundation in Go through hands-on practice, experimentation, debugging, and problem-solving.

## Topics Covered

- [ ] Basics and program structure
- [ ] Variables, types, and constants
- [ ] Control flow: loops and conditionals
- [ ] Functions and multiple return values
- [ ] Pointers
- [ ] Structs and methods
- [ ] Arrays and slices
- [ ] Maps
- [ ] Function values and closures
- [ ] Interfaces
- [ ] Errors
- [ ] Generics
- [ ] Concurrency: goroutines and channels

*Topics will be checked off as I work through them.*

## Learning Approach

- Write code instead of only reading examples.
- Experiment with different inputs and approaches.
- Debug errors and understand why they happen.
- Revisit concepts that are not yet clear.
- Commit practice regularly to track progress.
